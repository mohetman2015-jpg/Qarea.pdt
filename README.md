# قارئي PDF — الإصدار الأول

تطبيق عربي بسيط لقراءة ملفات PDF على الهاتف والتابلت والكمبيوتر، مبني باستخدام React وVite وPDF.js.

## ما يتضمنه الإصدار الأول
- فتح ملف PDF من الجهاز محليًا دون رفعه إلى خادم.
- عرض الصفحات والتنقل بينها والتكبير والتصغير.
- التظليل والرسم والكتابة فوق الصفحة مع حفظ العلامات محليًا.
- البحث في النص المستخرج من صفحات المستند.
- قراءة نص الصفحة بصوت المتصفح عند توفر صوت عربي.
- الوضع الليلي وحفظ آخر صفحة تمت قراءتها.
- إعداد PWA للتثبيت بعد نشره عبر HTTPS.

## التشغيل
يتطلب Node.js 20 أو أحدث واتصالًا بالإنترنت أول مرة لتنزيل الحزم:

```bash
npm install
npm run dev
```

ثم افتح العنوان المحلي الذي يظهر في الطرفية.

## بناء نسخة النشر
```bash
npm run build
npm run preview
```

انشر محتويات مجلد `dist` على استضافة HTTPS لتفعيل التثبيت كتطبيق PWA.

## حدود الإصدار الأول بشفافية
- البحث وتحويل النص إلى صوت يعملان على النص الموجود داخل PDF. الملفات المصورة/الممسوحة ضوئيًا تحتاج OCR، وهو غير مضاف بعد.
- جودة الصوت العربي وتوفره يعتمدان على نظام التشغيل والمتصفح.
- العلامات محفوظة محليًا كطبقة على الصفحة ولا تُدمج داخل ملف PDF الأصلي في هذا الإصدار.
- لا يوجد حتى الآن تصدير نسخة PDF بعد التعديل أو مزامنة بين الأجهزة.
- الملفات لا تغادر الجهاز عند فتحها؛ تُعالج داخل المتصفح.
